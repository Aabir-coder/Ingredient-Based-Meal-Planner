# 🍽️ Ingredient-Based Meal Planner

An interactive frontend web application that helps users discover recipes based on the ingredients available in their kitchen. Instead of selecting available ingredients, users simply mark the ingredients they **don't have**, and the application instantly filters out recipes requiring those ingredients.

## 🚀 Features

- 🥗 Preloaded recipe database
- ❌ Select unavailable ingredients
- 🔍 Real-time recipe filtering
- 📋 View recipe ingredients and cooking steps
- 📅 Weekly meal planner
- ❤️ Save favorite recipes
- 💾 LocalStorage support
- 📱 Responsive design
- 🌙 Dark/Light mode

## 💡 How It Works

1. The application contains a predefined list of recipes.
2. Each recipe has its required ingredients.
3. Users select the ingredients they **do not have**.
4. Recipes containing those ingredients are automatically removed.
5. Only recipes that can be prepared with the remaining ingredients are displayed.
